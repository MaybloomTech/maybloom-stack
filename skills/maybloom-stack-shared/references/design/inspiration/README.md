# Inspiration

A library of sources a designer can draw from, each tagged by the kind of
screen it helps with. A source is not a template: it lends a way of seeing,
and the direction still has to be the product's own.

## Adding a source

One file per source, `inspiration/<name>.md`, saying:

- **What it lends:** a register (type, density, colour posture, shell), a
  component vocabulary (the objects it names and how they behave), or both.
- **Which screen kind:** app screens, reading pages, or something more
  specific (an agent-facing tool, a data-heavy admin).
- **Its licence,** and which parts it covers: what is open and what is not.
- **What is never copied:** code, assets or a closed design, per the
  licence. A source with closed parts is built from its public
  documentation only.

Keep each entry short: a designer loads the ones that fit, not all of them.
